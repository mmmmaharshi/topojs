BOUNDARY SENSITIVITY SWEEP
Generated by: npm run bench:boundary  (node --experimental-strip-types bench/boundary-sensitivity.ts)

PURPOSE. sparse-rips.ts proves d_B(Dgm(Rips(X)), Dgm(Rips(L))) <= 2*coveringRadius
for the FULL (untruncated) Rips filtration, then states an unmeasured caveat:
pairs whose birth/death lands near this library's `maxDist` truncation are
"not covered by the bound with the same confidence ... not yet proven
tightly." The existing test suite (test/sparse-rips.test.ts) deliberately
keeps maxDist "well above typical pair values" to avoid the boundary region,
so this caveat had never been empirically checked. This sweep checks it
directly with synthetic random point clouds swept across a wide, deliberately
adversarial maxDist range (correctness/bound characterization -- not a
performance claim -- so CLAUDE.md's real-data-only benchmark policy does not
apply here; see file header for the distinction).

RESULTS (dims 0-1, 800 trials, maxDist swept 0.03-0.78 including extreme
truncation, numLandmarks 15%-70% of n):
  INTERIOR group: n=373, violations=0 (0.00%)
  BOUNDARY group: n=559, violations=0 (0.00%)
  TOTAL: 0/932 = 0.00% violated

RESULTS (dims 0-2 incl. H2, 120 trials, maxDist swept 0.05-0.75):
  INTERIOR: n=173, violations=0 (0.00%)
  BOUNDARY: n=59, violations=0 (0.00%)
  H2-INCLUSIVE TOTAL: 0/232 = 0.00% violated

GRAND TOTAL: 0/1164 (trial, dimension) comparisons violated the bound, across
both interior and boundary-flagged groups, across dims 0-2, across maxDist
values deliberately chosen to be as small as 0.03 (extreme truncation,
sometimes smaller than the bound itself).

HONEST INTERPRETATION. This is empirical evidence, not a proof. Zero
violations across 1164 deliberately adversarial comparisons is a meaningfully
larger and harder sweep than anything previously run against this caveat, and
it suggests the practical risk near the truncation boundary is low. It does
NOT close the formal gap: sparse-rips.ts's docstring still correctly states
the theorem is proven only for the untruncated filtration, and a
counterexample could in principle exist outside this sweep's parameter
ranges (n=12-36, dims 2-3, numLandmarks 15%-70% of n). Treat this as raising
confidence, not as a substitute for a real proof of the truncated-filtration
case.
