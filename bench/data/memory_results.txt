UPDATE 2: a SECOND pooling fix was applied after the first (see UPDATE
below) -- triOrder specifically, not edgeOrder. A process-isolated
diagnostic (build an instance, strip everything BUT one field, measure
heap; see the commit that introduced this) found triOrder (T separate
7-field TriRec objects) was ~83% of the ~1.9MB retained state remaining
after UPDATE 1's fix, versus edgeOrder's much smaller ~11% -- so triOrder,
specifically, was pooled into 7 parallel typed arrays (triIdA/B/C, triVal,
triE1/E2/E3), while edgeOrder was deliberately left as an array of objects
(its contribution wasn't big enough to justify the added risk). Same
low-risk pattern as before: reduction algorithm untouched, only the
retained-state storage boundary changed. Verified via the same 123/123 (now
124/124, one new long-running stress test added) passing test suite.

COMBINED effect of both fixes, ORIGINAL -> after both, at windowSize=80:
  sunspots:        4.864 MB -> 0.209 MB  (23.3x less)  ratio: 3484x -> 149.9x
  melbourne-temp:   1.943 MB -> 0.037 MB  (52.5x less)  ratio: 1361x -> 25.7x
  iris (windowSize=20): 0.205 MB -> 0.028 MB (7.3x less)

This closes the large majority of the originally-documented gap. Smaller
window sizes (10, 20, 40) are now genuinely noise-dominated in the
measurement (absolute deltas are down to single-digit-to-low-double-digit
KB, comparable to the harness's own documented noise floor) -- windowSize=80
is the only point still large enough to read cleanly; see the current main
tables below for the honest picture at every size, including the noisy
smaller ones (not cherry-picked to only show the clean result).

Still does NOT eliminate the time/space trade-off: edgeOrder (array of
EdgeRec objects), neighborsOf (Map<number,Set<number>>), and pointCoords
(array of small arrays) remain unpooled, and IncrementalH1 still retains
meaningfully more than StreamingHomology's near-zero footprint. See
README.md's "Space, not just time" section for the summary writeup and
the reasoning for stopping here rather than continuing to pool the
remaining, much smaller contributors.
