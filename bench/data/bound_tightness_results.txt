BOUND TIGHTNESS SWEEP
Generated by: npm run bench:tightness (node --experimental-strip-types bench/bound-tightness.ts)

PURPOSE. test/sparse-rips.test.ts checks that d_B <= bound holds across
hundreds of random configs, but never reports HOW tight the bound is --
only that it holds. A bound that holds but is 50x looser than the actual
error is far less useful to a caller than one that's 1.2x loose. This
measures the ratio actual_dB / bound directly.

RESULT 1 -- Infinity-mismatch rate (previously unreported). Across the
random-config sweep (n=600 (trial,dim) comparisons attempted), 208/600
(34.7%) returned db=Infinity -- an essential-pair-count mismatch between the
exact and landmark diagrams (typically at small landmark budgets, where the
subsampled complex has a different number of never-merged / never-filled
components or loops than the full complex at the same maxDist).
test/sparse-rips.test.ts already excludes these via `if (db !== Infinity)`,
which is correct (bottleneck distance is undefined/infinite when essential
counts differ), but the EXCLUSION RATE had never been reported anywhere in
this repo -- roughly a third of all bound-checks in the existing test suite
are silently skipped, not checked.

HONEST INTERPRETATION. The bound is real and holds (see bench/boundary-
sensitivity.ts + the existing test suite), but it is conservative by roughly
a factor of 4-15x in the regimes measured here: median ratio 0.19 on random
configs, and H0/H1 ratios of 0.04-0.28 on real Iris data across landmark
budgets from 10 to 130. In practice, the actual approximation error a caller
gets is usually well under a quarter of what the 2*coveringRadius guarantee
promises -- useful to know when deciding whether a given landmark budget is
"good enough," since the worst-case number alone would suggest a much worse
approximation than what's typically realized. The looseness is expected: the
theorem bounds the WORST case over all possible perturbations consistent
with the covering radius, not the specific perturbation a farthest-point-
sampled landmark set happens to realize.
